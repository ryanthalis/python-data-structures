# Searching Algorithms

Sequential and binary search implementations that return the matching index or
`-1` when the target is absent.

## Run the tests

```shell
python -m unittest -v test_searching.py
```

## Complexity

| Algorithm | Time | Space |
| --- | --- | --- |
| Sequential search | O(n) | O(1) |
| Binary search | O(log n) | O(1) |
