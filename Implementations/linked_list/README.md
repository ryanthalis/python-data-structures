# Linked List

A compact singly linked list implemented in Python. It supports iteration,
appending, membership checks, equality comparison, indexed deletion, and
removal of the first matching value.

## Run the tests

```shell
python -m unittest -v test_linked_list.py
```

## Complexity

| Operation | Time |
| --- | --- |
| `append` | O(1) |
| `len` | O(1) |
| membership | O(n) |
| equality | O(n) |
| indexed deletion | O(n) |
| remove by value | O(n) |
