# Python Data Structures and Algorithms

A growing collection of data structures and algorithms implemented in Python,
with focused unit tests and complexity notes for each component.

## Project status

- [x] Singly linked list
- [x] Dynamic array
- [ ] Stack
- [ ] Queue
- [ ] Hash table
- [ ] Binary heap
- [ ] AVL tree
- [ ] Graph
- [ ] Sorting and searching algorithms

## Running tests

Run the completed linked-list tests from the project root:

```shell
python -m unittest discover -s Implementations/linked_list -p "test_*.py" -v
```

## Planned structure

Each component has its own implementation, minimal test suite, and complexity
documentation. Additional components will be added incrementally as they are
completed.
